# DSA Tracker — Frontend Client

Personal DSA learning roadmap & progress tracker application built with Vanilla HTML5, CSS3, and modern JavaScript.

## Features

- **Unlock System**: Only completed topics are interactive; locked topics display 🔒 status.
- **Canonical Roadmap**: 12 structured topics in exact order.
- **Responsive Layout**: CSS Grid layout (`auto-fill`) preventing uneven row alignment on all screens.
- **Theme Support**: Dark / Light theme toggle with persistence.
- **Notes & Backup**: Embedded notes panel + JSON Export/Import/Reset.

## Quick Start

```bash
# Serve frontend on http://localhost:5500
npm start
```

Or open with VS Code Live Server extension.
